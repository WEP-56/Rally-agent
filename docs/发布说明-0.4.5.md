# Rally 0.4.5

这一版完善持续运行的个人助手体验：消息忙时不丢、长期闲置暂停消耗，任务可按需获得对话与记忆背景。

## 新增与改进

- **统一消息收件箱**：桌面、云端、飞书和 QQ 的消息先保存，再按顺序逐条处理。排队消息可撤回，失败消息可重试；停止回复会暂停后续队列。重启恢复未开始的消息，处理中断的消息需明确重试，避免重复执行已有操作。
- **IM 回复回传**：回复保存后回到原来的 IM 消息，断线时保留。回传失败只重发已保存的文字，不重复调用模型；平台拒绝延迟回复时，完整结果仍可在 Rally 查看。
- **默认闲置保护**：连续 72 小时没有真实用户发言，暂停主 Agent、Worker、教练、定时派发、后台回告及托管进程。下一条用户消息恢复活动；打开客户端、查看任务或重复消息不会重新计时。
- **更简单的 Worker 背景**：派发、修改、续接与创建定时任务可使用 `context:0–30` 和 `memory:0/1`。由 Rally 自动复制最近对话轮次，或携带现有三份记忆全文；默认不携带，不再要求模型先检索消息 ID、摘录原文。原话仍是任务需求与权限的依据。
- **世界感知**：主 Agent 与内置 Worker 可按需查询时间、查找地点和获取天气。地点来自用户提供的信息或当前任务，不自动定位，也不持续注入变化中的时间、天气或队列状态。
- **更丰富的定时任务**：支持间隔加运行时段、跨午夜时段、指定星期，以及在原计划内修改时间。休息时段不补跑；上一轮未处理完时显示等待原因，避免重复启动。
- **连接器工具权限更容易找到**：飞书和 QQ 邮箱的工具统一在「连接」页对应连接器内展示与设置，设置真实影响执行；MCP 页继续管理用户自行配置的 MCP 服务。
- **界面减负**：工位移除介绍、模型/记忆标签、状态横幅、统计卡和本地服务区，头像与名称下直接展示任务。设置导航按个人助手、模型与能力、工作与账号、应用分组。
- **修复与兼容**：修复模型目录变动导致的 9 处测试数据错误；保留旧对话、任务、计划与连接器配置。外部执行器继续按需安装，不重新装入基础包。

## 下载与升级

- Windows：`Rally-0.4.5-setup.exe`
- Linux x64：`rally-server-0.4.5-linux-x64.tar.gz`
- Android：按设备 ABI 选择一个 `Rally-0.4.5-android-*.apk`，沿用原正式签名。
- `SHA256SUMS` 包含上述五件产物的 SHA-256 摘要。

本地和云端客户端建议与执行主机一起升级，以使用新的消息状态与队列操作。升级后，历史对话不会被当成新消息重新执行；已有任务、记忆、计划和账号数据保留。长期未发言的实例启动后可能直接进入闲置保护，发送新消息即可恢复。

开发侧已通过定向离线测试、类型检查与构建；发布流水线继续执行三平台打包、签名和产物检查。真实平台延迟回传、实际模型表现及设备视觉由用户使用验收。主 Agent 对 Worker 汇报的静默选择扩展、审批等待时长调整不在本版范围内。
