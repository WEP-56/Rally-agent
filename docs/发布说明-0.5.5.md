# Rally 0.5.5 · 更懂你，也能连接更多工具

这次更新让 Rally 更自然地与你相处，也补齐了远程服务器、外部 Agent 和日常任务管理的能力。

- **平等、有好奇心的个人助理**：完善关系定位，强调相互尊重、独立判断和坦然纠错；鼓励在谈话中自然了解你的兴趣、偏好和想法。
- **新增 SSH 连接器**：在「连接」页管理多台服务器，支持密码或私钥、指纹确认、连接验证与工具权限。任务可执行远程命令，并持续处理交互式会话。
- **更顺畅地使用 Claude Code / Codex**：内置连接层，自动发现任务主机上已有的 CLI，复用已有登录和模型配置，也支持自定义程序路径。
- **密码本适用于更多场景**：账号与密钥可供浏览器、命令行、API 和脚本使用，缺少凭据时通过私密表单补充。
- **定时任务可以直接修改**：调整执行内容、时间和背景时保留原计划及历史，无需删除重建。
- **日常体验修复**：减少任务卡与看板带来的上下文负担，改善任务背景传递与部分 HTML 内嵌展示，修复 Windows 浏览器标签关闭时的错误。
- **Linux 安装修复**：确保外部 Agent 连接层随服务端正确安装。

Windows、Android 与 Linux 服务端统一为 **0.5.5**。外部 Agent 的 CLI 与登录需要在实际运行任务的电脑或服务器上准备。

部署说明见 [Linux 部署指南](https://github.com/WEP-56/Rally-agent/tree/v0.5.5/deploy/linux)。
