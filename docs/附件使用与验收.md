# 附件使用与验收

2026-11-21。用户已实测新增附件系统，仅报告 Android 附件上传问题：点击添加附件后文件选择器无响应，模拟器和真机均复现。其它附件能力没有新增问题反馈。Android 上传尚未修复，下一会话优先处理；用户已连接模拟器 ADB `127.0.0.1:5555`，修复后需验证原生选择器到完整上传链路，仅推送代码、不发布更新。

本机测试包在 `release/`：`Rally-0.1.0-setup.exe` 和带 ABI 的三个 `Rally-0.1.0-android-*-debug.apk`；对应摘要为 `SHA256SUMS-testing`。本机旧通用 APK、Linux tar.gz 和 `SHA256SUMS` 不包含本轮全部改动。现有 VPS 已于 2026-11-21 更新至正式 `v0.1.0`，可继续验收云端附件收发。

GitHub `v0.1.0` 已转为正式 Release，提供 Actions 构建的 Windows、Linux 和三个正式签名 APK，建议验收这套发布产物并核对随附 SHA256SUMS。正式 Android 签名与此前调试包不同，不能直接覆盖调试包；本次未在现有设备上卸载或更换客户端。Windows 任务栏图标修复与新增开机自启目前仅在源码中，随下次版本更新交付。

## 发送与接收

在聊天输入框粘贴图片、拖入文件或点击附件按钮选择文件，文件进入同一队列。Android 设计为调用系统文件选择器并支持多选，但当前实测点击无响应，不能视为可用。每条消息最多 10 件，每件最多 1 GiB，同时上传 2 件；服务器每个设备未完成上传最多 10 件、总量 2 GiB。

全部上传完成后可发送，也可以只发附件。失败保留文字和队列，重试先查询服务器 offset 再继续；服务器已清理临时上传时会重新开始。移除正在上传的项会取消。关闭页面后不会保存本机 File 句柄，重新打开需要再次选择文件。

消息和任务页显示附件卡片；点击在右侧新建标签，同一资源重复打开复用标签。手机使用全屏工作台，返回键回到原视图。图片卡片按可见范围请求缩略图，事件同步和 IndexedDB 缓存仅含元数据。

## Agent 能力

- 支持图像输入的模型收到经过 Pi 处理的真实 image block；非视觉模型收到文件引用和明确的能力提示。单次内联图片预算为 10 件、原始文件合计 32 MiB，超出部分通过工具读取。
- 主 Agent 和 Worker 可用 Pi `read` 读取执行目录的图片，返回的图像同时登记为用户可见预览；登记不会移除模型端的图像块。
- Agent 使用 `resource_publish` 发布目录文件或已有资源；发布时复制原件，项目文件后续变化不改变历史附件。
- Worker 发布产物随任务汇报出现在主对话，任务原话、追加指令和上下游任务传递保留资源引用。
- 音频、视频和普通文件可以传递给工具处理；当前不把它们伪装为通用模型音视频输入。生成服务通过工具/MCP/脚本接入，再发布结果文件。

## 预览与保存

| 类型 | 当前行为 |
| --- | --- |
| PNG/JPEG/GIF/WebP/BMP | 图片预览与缩略图，实际解码能力取决于客户端 |
| 纯文本与常见代码文件 ≤1 MiB | 转义后的纯文本预览 |
| 支持的音频、视频容器和编码 | 系统内核播放控件、Range 拖动定位 |
| PDF、Office、压缩包、HTML、SVG 等 | 元数据与下载，不在应用内执行主动内容 |

预览票据有效期 2 分钟，过期或解码失败时点击刷新；正在持续传输的响应可以完成，过期后的新 Range 请求需重新申请。原件不进入文本缓存。Windows 使用保存对话框与同目录临时文件，Android 使用系统保存位置与应用缓存暂存；完成大小和 SHA-256 校验后保存。可查看进度、取消；取消或失败清理临时文件。原生下载目前重新下载整件，HTTP 接口支持 Range，但下载队列尚未实现跨重启续传。

## 保留与恢复

资源保存在 Agent 运行位置的 `~/.rally/resources/`。新会话和归档保留资源；彻底删除任务只释放其引用，共享消息、其他任务或上下游输入仍引用的文件保留。

启动先从全部主对话历史和现存任务恢复引用，再清理超过 24 小时的临时上传、未发送资源和无引用文件，之后每小时维护。事件恢复发现损坏时停用自动回收并保留现有引用。缺失文件显示不可用，不凭空恢复内容。清理只作用资源库的托管文件，绝不删除项目源文件。

备份需同时保存 `resources.sqlite`、原件目录和业务事件/会话。建议停止运行时后复制整个业务目录，不能只拷贝 SQLite 主文件而遗漏活动 WAL。跨服务器迁移需连同控制台设备数据和加密密钥迁移；仅复制某个附件文件不会自动生成引用。

## 用户验收路径

1. Windows 本地：粘贴图片、拖文件、移除一项，确认队列；只发图片，请主 Agent 查看，再派给任务 Agent。
2. 请 Agent 读取项目目录图片；检查消息卡、新标签、再次打开、源文件修改后历史预览不变。
3. 让任务生成文字/图片文件并发布；在任务页和主对话预览、下载，核对内容。
4. Windows 与 Android 连接同一测试服务器：一端上传另一端查看，下载到各自系统选择的位置。
5. 断网后重试上传、取消下载、资源缺失；检查错误提示，确认不重复发送消息。
6. 选择已知可播放的 WAV/MP4；检查播放与定位。未知格式应仍可下载。
7. 托盘关闭行为：本地收起后任务继续，点击图标恢复；明确退出停止本机工作。云端退出客户端后服务器任务继续。
8. 下一版 Windows 桌面修复：检查运行窗口与固定任务栏项的 Rally 图标；在设置 → 桌面行为打开/关闭开机自启，重新登录后确认是否启动。开机自启和关闭至托盘各自生效；在任务管理器禁用自启后切回 Rally，开关应同步关闭。云端断线时仍可改本机设置，Android 不出现此项。

离线测试位于 `tests/attachments/`，涵盖生产主 Agent/Worker faux-provider 图像输入、发布与重启、分块断点、跨设备权限、票据/Range、活跃传输吊销、下载完整性、引用恢复和构建后的 renderer 交互。测试不会继承真实模型密钥；没有把这些测试视作视觉或真实供应商验收。
