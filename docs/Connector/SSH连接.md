# SSH 连接

SSH 连接器让内置 Worker 使用你配置的服务器执行维护任务。Windows 本地模式从电脑连接；云端模式从运行 Rally 的服务器连接。Android 使用同一云端配置。

## 配置

在「连接 → SSH → 管理」添加服务器，填写名称、地址、端口（默认 22）、用户名，以及密码或私钥。私钥可以粘贴，也可以导入文件；有口令的私钥另填口令。

保存后点击「测试连接」。首次连接会显示服务器指纹，与服务器提供的信息核对后点击「确认并验证登录」。指纹变化时需要重新确认，助手不能代替你接受。验证成功不表示后台始终保持连接，实际执行时才连接。

编辑时不重新填写密码/私钥会保留原值。口令不编辑时保留；输入后清空可移除原口令。切换认证方式需要填写对应的新凭据。编辑、停用或删除会关闭此配置现有的连接；关闭连接不保证远端子进程已经停止。

登录秘密保存在执行主机 `ssh-connections.json` 的加密字段中，沿用 Windows 系统凭据存储或 Linux 部署 vault key。客户端查询和模型工具不返回密码、私钥或口令。运行中的程序需要 sudo 等额外凭据时，Worker 可使用密码本引用，无需在普通聊天里填写明文。

## 使用

配置好以后直接提出要求，例如“看看我的香港 VPS 磁盘为什么满了”。主助手派发给内置 Worker；新建或重新启动的 Worker 在存在启用的 SSH 配置时加载三个工具：

| 工具 | 用途 |
| --- | --- |
| ssh_list | 查看服务器名称和 ID |
| ssh_exec | 执行命令；未结束时返回会话 ID |
| ssh_write_stdin | 继续读输出，或向同一个程序发送输入 |

默认执行命令和发送输入接入现有审批流程；可以在 SSH 卡片的「工具权限」调整。继续会话的纯读取不审批，输入才按所选档位执行。工具权限不替代用户对任务的授权。

纯读取只需会话 ID。模型多填的空输入、空凭据 ID 会按未填写处理，不会发送回车或弹出输入审批；非空凭据引用仍须存在且启用。

输出分段、增量返回，完整脱敏日志保存在执行主机的任务作业日志目录。有限长命令结束后通知 Worker，通知不重复整份日志。交互程序由 Worker 持续读取和回答；正常退出 shell 使用 exit，PTY 模式支持 Ctrl+C。

任务结束、取消或应用退出会关闭连接；断线和重启不自动恢复会话或重跑命令。结果不明时由 Worker 新开命令检查远端实际情况。旧日志仍可在同一任务续接时读取；重启后读取位置从头开始。

首版面向 Linux/POSIX SSH 服务器，没有终端界面、SFTP 文件管理、跳板机或通用多因素认证。外部 Claude/Codex 执行器不桥接这些内部工具。
