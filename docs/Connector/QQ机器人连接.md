# QQ 机器人连接

Rally 使用腾讯官方 QQ 机器人 Node.js SDK 建立 WebSocket 长连接，不需要部署公网回调。首版只接收**一个已配对 QQ 账号的私聊文本**，共用桌面主对话，并回复触发该轮的 QQ 消息。Rally 退出后停止接收；群聊、附件、桌面回复和后续任务通知不会同步到 QQ。

## 配置和配对

1. 根据[腾讯的 Agent 接入指南](https://bot.q.qq.com/wiki/agent-qqbot/#快速创建一个-qq-机器人)创建自己的 QQ 机器人，从管理端获取 AppID 和 AppSecret。根据[腾讯机器人 FAQ](https://bot.q.qq.com/wiki/bot_FAQ/)，新版管理端的管理员账号可以直接测试；个人主体的机器人如需让其他账号测试私聊，可在「开发设置」添加开发体验用户。
2. 在 Rally 右侧栏打开「＋ → 连接」，展开「QQ」，填写 AppID 和 AppSecret，点击「保存并连接」。密钥使用系统凭据加密保存在本机，不会重新显示。
3. 状态显示「已连接」后，点击「生成配对码」。在手机 QQ 中与机器人私聊，发送页面显示的 `/pair …`。配对码 5 分钟内有效且只能使用一次。确认收到配对成功，再发送普通文本。
4. 如需换绑 QQ 账号，在 Rally 点击「断开连接」，重新保存连接并配对。正常退出和重启 Rally 会保留配置与配对；连接失败时可点「重连」，并检查机器人状态和凭据。

## 验收

- 先在桌面主对话交代一个上下文，再在 QQ 私聊追问，确认 QQ 回复能接上桌面上下文，桌面也出现带「来自 QQ」的消息。
- 在 QQ 发一个只读任务，确认任务卡的原话引用标有「来自 QQ」；桌面独立回复和任务完成通知不发送到 QQ。
- 配对之后，用另一个有平台体验资格的 QQ 账号发私聊，确认不会进入 Rally。断开连接以后再发给机器人，确认也不进入主对话。

实现依据：[腾讯官方 QQ 机器人 Node.js SDK](https://github.com/tencent-connect/qqbot-nodejs) 的长连接、C2C 事件和消息回复接口；私聊访问控制参考[腾讯 DeepSeek Harness 插件](https://github.com/tencent-connect/dsh-qqbot)。

## 消息排队与恢复

忙时收到的私聊先保存，按顺序处理，不再回复“稍后再发送”。每条结果仍回到原消息。断线时保留待回传文字，原账号重连后发送；平台拒绝或发送结果不明时，可在 Rally 的原消息下查看、重发或取消回传。重发回复不重复调用模型。未开始的消息重启后恢复，进行中被中断的消息需用户明确重试；详见[用户消息收件箱](../用户消息收件箱.md)。
