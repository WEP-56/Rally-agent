# Rally 0.5.6 · 漏洞修复与稳定性更新

这次更新集中修复排查服务中断时发现的上下文、日志存储和审批恢复问题。

- **修复大型审批撑爆对话**：批量删除的完整清单独立保存，审批保留范围、数量与风险摘要，批准前校验证据，删除前再次检查文件。超大的其它工具审批转交用户查看完整证据后确认。
- **修复删除日志急剧膨胀**：逐文件保留审计记录，避免每删除一个文件就重复保存整个任务；重启与快照恢复仍能还原完整变化文件列表。
- **完善上下文与压缩保护**：发送前把动态快照计入输入预算，过大历史结果分块压缩；仍超限时停止发送并说明原因，压缩失败也会显示。未通过发送检查的中继保留待处理。
- **减少重复注入**：任务详情与变化文件分页，删除预览和失败列表限制体积，定时工具只返回轻量回执；大结果保留完整文件供按需读取。记忆、教练输入、任务状态及中继批次也有明确预算。
- **恢复历史搜索**：部分采纳 PR #10，新建会话或重启后仍可搜索旧消息；结果明确标记当前可引用的用户消息，旧会话内容不会自动获得新授权。
- **修复历史审批恢复异常**：过长范围或正文中出现类似审批标签的文本，不再阻止主会话恢复。

Windows、Android 和 Linux 服务端统一更新至 **0.5.6**。现有对话、记忆和审计历史保留；本次更新不自动删除旧日志或业务文件。
