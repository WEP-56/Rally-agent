# Rally 0.5.0 · 换上新衣，继续陪你 ✨

这次，Rally 有了新模样：更柔和的界面、更轻快的动效，还有一位藏在新图标里的小伙伴。

- **全新 MD3 界面**：统一主题色、圆角组件和弹簧动效，聊天、工位、设置与弹窗一起焕新。
- **聊天更顺手**：输入框向下展开，附件和提及固定在顶部；暂停队列、撤回与重试改为简洁图标，顶栏使用真正的背景模糊。
- **设置更清楚**：整理其它提供商页面，修复密钥显示按钮与下拉菜单定位。
- **Worker 更好收拾**：已中断及停止执行的受阻任务可以归档，撤销归档不会自动重跑，需要继续时可明确续接。
- **云端管理页焕新**：统一 MD3 风格，新增设备总数、已配对、等待配对和最近在线统计。
- **新的品牌图标**：应用界面、Windows 窗口与托盘、安装器、Android 和管理页统一换装，README 也变得轻松了一点。

Windows、Android 与 Linux 服务端版本统一为 **0.5.0**。下载对应平台的安装包即可；部署与备份步骤见 [Linux 部署指南](../deploy/linux/README.md)。
