调研日期：2026-11-22。源码固定在 [`c923b02d8f74108fcb46758bbfc96b39f3cd7de6`](https://github.com/w01fb0ss/PiBot/commit/c923b02d8f74108fcb46758bbfc96b39f3cd7de6)。这次只读源码，没有安装或运行 PiBot，也没有用官方中继发起配对。下列链接均指向该提交。

## 手机如何连接电脑

1. **生成邀请。** 桌面端「设备」设置调用 `RemoteService.pairStart()`，`PairingManager` 先取消旧邀请，再生成一条 10 分钟内有效的邀请。二维码携带协议版本、到期时间、中继地址、电脑公钥和一次性预共享密钥。配对用临时房间，桌面端等握手确认后才写设备记录和房间凭据。依据：[服务入口](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/runtime/service.ts#L443)、[邀请状态与提交](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/pairing/manager.ts#L42-L133)、[二维码编码与过期校验](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/link/src/pairing/qr.ts#L16-L103)。
2. **扫码建立信任。** 手机生成自己的身份密钥，按二维码加入临时房间，通过 Noise `IKpsk2` 握手；双方在加密通道中交换绑定握手的身份签名。手机按二维码公钥验证电脑，双方通过共享密钥和一段新随机数据导出后续房间密钥。配对完成后，手机要用常规连接调 `devices.self` 确认电脑身份，再保存凭据。手机使用 Expo SecureStore 持久化凭据，电脑经现有 secrets 接口保存房间凭据。依据：[手机握手](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/mobile/src/transport/pair-channel.ts#L24-L101)、[电脑握手与确认](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/link/adapter.ts#L92-L176)、[确认电脑身份](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/mobile/src/transport/real-link.ts#L413-L445)、[手机存储](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/mobile/src/storage/native.ts#L77-L86)。
3. **配对后的连接。** 手机检查已保存的公钥和中继与目标匹配。有 LAN 线索时尝试局域网连接；中继路径通过 WebSocket 建立加密通道，随后可协商 WebRTC 直连，直连丢失时可切回中继。常规握手用不带一次性 PSK 的 `IK`，房间票据随时间轮换；真正的对等身份仍由握手和保存的设备公钥校验。中继的 Worker / Durable Object 管房间准入和消息转发，看到连接角色及密文，不处理对话、审批等业务请求。依据：[手机选路](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/mobile/src/transport/real-link.ts#L446-L478)、[Noise 模式](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/link/src/noise/handshake.ts#L34-L50)、[房间票据](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/link/src/room/ticket.ts#L13-L64)、[链路切换](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/link/src/transport/path-session.ts#L248-L312)、[中继房间](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/relay/src/room/room.ts#L105-L151)。
4. **业务通信单独授权。** 电脑为已配对手机绑定 `phoneGateway`。请求走加密链路中的 RPC，按方法清单、客户端范围和参数放行；配对不等同于拥有全部桌面能力。事件有序号，手机重连时用 `events.resume` 补缺口；补不了才换新流并刷新。前后台与换路径由客户端会话管理，不要求界面重新绑定每次底层连接。依据：[绑定网关和事件流](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/sessions/connections.ts#L330-L368)、[手机方法清单](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/rpc/allowlist.ts#L55-L122)、[请求检查](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/rpc/gateway.ts#L172-L219)、[手机补事件](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/mobile/src/transport/session.ts#L470-L541)。

## 浏览器如何被 Agent 和用户调用

| 路径 | 实现与边界 |
| --- | --- |
| Agent → 内置浏览器 | `browser_open`、`browser_snapshot`、`browser_click` 等经工具执行层和 Brain 的浏览器服务，转为 `host.browser.*` 调用；实际网页运行在桌面宿主的 Electron 标签窗口中。标签使用隔离的浏览器 Session、开启 sandbox、关闭 Node 集成。宿主通过 CDP 读页面、做截图和点击；快照里的元素引用绑定当前文档，导航后需要重新快照。域名、内网和表单提交等检查在工具与宿主间协作，也有运行租约。依据：[工具转宿主调用](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/browser/src/brain/service/browser-actions.ts#L36-L122)、[宿主注册](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/browser/src/host/host.ts#L260-L331)、[标签配置](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/browser/src/host/tab/tab-shared.ts#L35-L54)、[引用失效](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/browser/src/host/page/actions.ts#L13-L21)、[审批回传](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/brain/src/runtime/tools/browser/browser-adapter.ts#L246-L283)。 |
| 手机 → 桌面内置浏览器 | 手机不是本地执行 Bot 网页；它调用 `remote.browser.frame` 拉取桌面同一浏览器的最新帧，接管后才用 `remote.browser.input` / `navigate` 操作。`PhoneBrowser` 把输入坐标映射回对应帧并检查设备占有者；另一手机或桌面正接管时不可抢占。离开页面、断线或会话超时收回接管，恢复 Agent 对页面的控制。依据：[手机端 RPC](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/mobile/src/features/browser/calls.ts#L12-L64)、[电脑接管与输入](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/remote/src/brain/browser/phone-browser.ts#L144-L240)、[共享最新帧](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/browser/src/host/frames/browser-frames.ts#L296-L345)。 |
| Agent → 用户自己的浏览器 | 另一条可选路径。运行设置允许且扩展在线时，部分 `host.browser.*` 操作经本机 Native Messaging 桥交给扩展；缺少扩展会回到内置浏览器。扩展路径上先检查目标和表单操作；内置浏览器接管、临时读页与登录工具不走此路径。扩展已有广泛网页权限，采用它需要独立审查登录态和权限边界。依据：[扩展路由](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/packages/browser/src/host/extension-route.ts#L85-L124)、[扩展到 Native Host](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/browser-extension/src/background.ts#L409-L443)、[桌面本机桥](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/desktop/src/main/browser-extension/extension-server.ts#L16-L85)、[扩展权限](https://github.com/w01fb0ss/PiBot/blob/c923b02d8f74108fcb46758bbfc96b39f3cd7de6/apps/browser-extension/manifest.json#L1-L14)。 |

## 对 Rally 最有用的部分

- **优先借鉴状态与恢复协议。** Rally 云端由自建服务器常驻执行，客户端经 HTTPS 配对并使用设备凭据、事件游标和附件票据。PiBot 手机主要远控电脑，直连和密文中继服务于这个拓扑。Rally 可独立借鉴分阶段连接状态、可补则补不可补则刷新、按设备撤销后立刻中止长连接等做法；没有必要为此替换现有云端协议。若未来要让 Android 直连 Windows 本地模式，再单独评估 LAN、密钥绑定、NAT 和离线恢复。
- **浏览器可借鉴租约和接管。** Rally 当前的 Windows 内嵌浏览器是用户工作台，`fetch_page` 只读静态网页；两者都不是 PiBot 式的 Agent 浏览器。若将来为 Worker 增加浏览器交互，可借鉴会话隔离、快照与元素引用、短期接管和失联归还；保留主 Agent 与 Worker 的分工。云端浏览器还需确定 Chromium 宿主、登录态和数据归属，不能把 Electron 本机扩展直接搬进 VPS。
