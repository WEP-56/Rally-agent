# Rally 0.4.0

本次更新新增角色 Workers、实验性的 Claude Code / Codex 外部执行器，以及内置的 Rally 自我管理 Skill，并修复浏览器接管、账密回告和 Linux 命令执行问题。

## 新增

- **角色 Workers**：在设置中创建角色，配置名称、头像、摘要、人设、工作方式、模型和推荐 Skills。主 Agent 可按任务选择角色；不指定角色时仍使用默认 Worker。
- **Claude Code / Codex 外部执行器（实验性）**：角色可选择外部执行器，从目标主机上的适配器读取可用模型，复用该主机已有的登录和模型配置。支持任务输出、工具执行状态、完成回报及取消清理。外部执行器不接入 Rally 的 MCP、浏览器或内部工具，不能替代依赖这些能力的原生 Worker；使用前需在实际执行任务的主机完成对应登录或配置。
- **Rally 自我管理 Skill**：设置页只显示一个 `rally-self-management`。身份与头像、教练、模型供应商、图像与搜索、MCP、Skills、角色和外部执行器的详细配置说明分为八份参考文件，按需读取，不再注册成多个 Skill。入口同时说明配置目录的发现方式。
- **Linux 随包提供 GitHub CLI**：固定携带 gh 2.105.0，构建时校验 SHA-256 并附许可证。用户数据目录中的工具与 GitHub 登录配置在升级时保留；首次使用 GitHub 仍需登录。

## 改进与修复

- 派发任务时明确补足 Worker 所需的用户引用、指代对象和最小背景，避免把主对话中只有主 Agent 知道的信息当作共享上下文。
- 询问卡片支持自由文本回答，不局限于预设选项，答案直接回传对应 Worker。
- 保存或取消账密申请后，结果会持久化回告主 Agent；空闲时唤醒、忙时插入当前处理，重复提交去重。回告仅包含状态和账号引用，不包含密码，也不表示已经完成网站登录。
- 修复浏览器接管时缺失视口尺寸导致点击失败的问题，减少轻微手抖被误判为拖动的情况，并修复接管画面额外遮挡。
- 修复 Linux 进程恰好退出时的清理竞态，避免命令和服务因误报进程清理失败而阻塞。
- 同步任务工具描述与提示词文档；桌面和 Linux 服务包均携带内置自我管理 Skill 及其参考文件。

## 下载与升级

- Windows：下载 `Rally-0.4.0-setup.exe`。
- Android：按设备 ABI 选择一个 APK（`arm64-v8a`、`armeabi-v7a` 或 `x86_64`），无需全部安装。
- Linux x64：下载 `rally-server-0.4.0-linux-x64.tar.gz`，按包内 README 安装或升级。
- `SHA256SUMS` 包含全部五件安装产物的校验摘要。Android 沿用正式签名；Windows 安装包未做代码签名。

升级前结束或妥善中断正在运行的任务，并备份配置及业务数据。外部执行器的登录和文件路径以实际执行主机为准；本地客户端的登录不会自动同步到云端服务。

## 验证说明

本地 supervisor 离线回归 100 项、外部执行器设置专项 3 项、应用构建及主进程/渲染进程类型检查通过；自我管理 Skill 已由用户运行确认。全仓类型检查仍有已记录的两个 AI 模型测试文件错误。正式产物由此版本 tag 的 Windows、Linux、Android 发布流水线构建和验证；真实外部模型调用与新增界面的完整设备验收不作为已经通过的验证。
