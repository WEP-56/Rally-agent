# Rally 0.5.1 · 让小伙伴一直陪着你

这次更新让 Rally 的品牌吉祥物真正融入聊天、工位和首次引导，也打磨了日常使用的小细节。

- **动态默认头像**：没有自定义头像时显示 Mochi 吉祥物；用户设置的头像保持原样。聊天顶部和工位会根据主 Agent 的思考、查询、派发、工具调用与回复状态切换动作。
- **首次引导更亲切**：设置头像时，小精灵会出现并提示“使用默认头像，我就能一直陪着你哦”。
- **聊天更清爽**：助手聊天气泡不再重复显示头像；外观设置可以减少动效，低性能和移动设备也会适当降低动画负担。
- **桌面体验打磨**：Windows 会沿用上次设置的窗口大小；右侧工位栏默认收起，可随时手动展开。

Windows、Android 与 Linux 服务端版本统一为 **0.5.1**。部署步骤见 [Linux 部署指南](../deploy/linux/README.md)。
