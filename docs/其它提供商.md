# 其它提供商：生图与网络搜索

在 **设置 → 其它提供商** 配置生图和搜索，聊天模型仍在 **设置 → 供应商**。本地模式保存到本机；云端模式保存到连接的服务器，同一服务器的已配对客户端共享配置。API Key 加密保存，客户端不会收到已保存的明文；编辑时留空保留原 Key。更换图像 API 基础地址时必须重新填写 Key。若另一台设备已保存或服务器已重启，请刷新后重新应用修改。

## 生图

1. 添加提供商，填写 API 基础地址（例如 `https://api.openai.com/v1`）和 Key。Rally 在地址后附加 `/images/generations`，只调用兼容 OpenAI 图像生成接口的服务。
2. 按提供商文档填写模型 ID，每行一个。可配置多家服务，选一个首选生图模型并保存。
3. 在主对话说清楚要生成什么；一次单张可以在主对话完成，批量、变体和设计要发布任务。生成的图片会作为附件出现，任务中的生成图也会随汇报返回，可预览或下载。

「图片返回方式」默认为「由提供商决定」，此时普通请求只发 `prompt` 和首选 `model`。如果提供商默认返回内网链接、且支持 `response_format: "b64_json"`，可选「Base64 图片数据」后保存；Rally 会在该提供商的请求中带上这个参数。张数 `n`、尺寸 `size`、质量、风格、背景及输出格式均按实际需要发送，不添加缺省值，也不限制 `size` 必须用 `1024x1024` 这种写法。若服务商明确说明端点默认就是所选模型，工具可省略 `model`；若必须传 `n`，主对话只能传 `1`。Worker 单次最多请求 4 张，实际数量和可用参数由模型决定。

服务明确拒绝参数时，可按该模型文档调整或省略不兼容字段，再试一次。若提示含糊或尚不清楚支持哪些字段，Agent 会询问该提供商的 API 文档；遇到超时、限额或网关错误，先检查服务端日志和额度。网关返回的请求 ID（如 `x-request-id` 或 `cf-ray`）会随错误显示，便于查日志。Rally 可接收 `b64_json`、公开 HTTPS 图像地址、内嵌 Base64 图片地址，以及直接返回的 PNG、JPEG、WebP。生成接口返回成功但未能取图时会单独提示，不会重新生成。

参考：[OpenAI Images 接口](https://developers.openai.com/api/reference/resources/images/methods/generate)。

## 搜索

为任意一家或多家输入 Key，再选一个首选搜索提供商。`web_search` 查询首选提供商，统一返回标题、链接、摘要及可用的发布日期，不会因失败切换到其它付费服务。需要读网页正文时使用 `fetch_page`；通用 `http_request` 只开放给 Worker。

| 首版支持 | 官方接口文档 |
| --- | --- |
| Tavily | [Search API](https://docs.tavily.com/documentation/api-reference/endpoint/search) |
| Exa | [Search API](https://exa.ai/docs/reference/search) |
| Brave Search | [Web Search API](https://api-dashboard.search.brave.com/app/documentation/web-search/get-started) |

此功能已用模拟 HTTP 响应和离线模型验证；不同提供商的生产参数、额度和界面显示仍需实测。现有 `v0.1.0` 发布包不含这批改动。
