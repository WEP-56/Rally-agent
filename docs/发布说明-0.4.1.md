# Rally 0.4.1

修复 0.4.0 将 Claude Code、Codex 及其原生运行时一起装入基础包，导致 Windows 和 Linux 下载体积大幅增加的问题。

| 下载包 | 0.4.0 | 0.4.1 |
| --- | ---: | ---: |
| Windows 安装器 | 521.83 MB | 250.18 MB |
| Linux x64 服务包 | 757.10 MB | 243.72 MB |

以上为 GitHub 正式产物体积（1 MB = 1,000,000 字节）；三平台发布检查全部通过，五件产物的 SHA-256 已与 GitHub 上传摘要核对。

## 修复

- **外部执行器改为按需安装**：Windows 和 Linux 基础包不再包含 Claude Code、Codex、它们的 SDK 运行时和 ACP 适配器。已有程序可复用；缺少组件时，在主对话中让 Rally 使用自我管理 Skill 安装或配置。打开角色设置、刷新模型不会自动下载程序。
- **复用设备环境**：支持用户目录、PATH 中的已有 CLI，以及 `external-agents.json` 指定的程序和适配器路径；保留已有登录和模型配置。按需安装的组件放在 Rally 用户数据目录，后续升级应用不会覆盖。
- **完善自管理说明**：补齐目标主机、配置文件位置、字段、安装命令和验证方法，仍然只有一个自管理 Skill。
- **修复 Linux 安装漏项**：安装脚本现在将随包的自管理 Skill 及参考文件装入正式运行目录。
- **增加发布检查**：检查依赖锁、Windows 实际打包内容及 Linux 生产目录，阻止再次把外部执行器及其大型原生依赖装入基础包。

## 使用与升级

Windows 下载 `Rally-0.4.1-setup.exe`；Linux x64 下载 `rally-server-0.4.1-linux-x64.tar.gz`。Android 按设备 ABI 选择一个 0.4.1 APK。`SHA256SUMS` 包含全部五件产物的校验摘要。

从 0.4.0 升级后，如果之前仅使用随包附带的外部执行器，需要让 Rally 配置已有 CLI 或按需安装对应组件，再在角色设置刷新模型；角色档案和外部 CLI 自身的登录配置保留。原生 Rally Worker 不依赖这些外部程序。本地客户端与云端执行主机各有自己的程序和登录环境。

外部执行器仍属实验性功能，不接入 Rally 浏览器、MCP 或内部工具。验证覆盖离线程序发现、ACP 会话、构建和打包；真实外部模型调用及界面视觉由用户验收。
