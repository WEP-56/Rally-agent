# 飞书连接

Rally 在本机通过飞书机器人长连接接收消息。需要创建一个企业自建应用。飞书组织的管理员可以限制应用发布、权限和可用范围；是否需要组织内审批以开放平台显示为准。

## 配置机器人和长连接

1. 在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，在应用能力中添加「机器人」。可用范围至少包含你用于配对的飞书账号。
2. 在「事件与回调」选择「使用长连接接收事件」，添加「接收消息」事件 `im.message.receive_v1`。在权限管理中，按照[接收消息](https://open.feishu.cn/document/server-docs/im-v1/message/events/receive)和[回复消息](https://open.feishu.cn/document/server-docs/im-v1/message/reply)文档，申请应用身份的单聊收消息和机器人发消息权限。创建版本并发布；如平台要求先建立长连接，先做下一步，再回来保存订阅并发布。
3. 打开 Rally 右侧栏的「＋ → 连接」（`Ctrl+4`）。展开飞书卡片，填写 App ID 和 App Secret，点击「保存并连接」。App Secret 由系统凭据加密保存在本机，连接页不会重新显示它。
4. 显示「已连接」后，点击「生成配对码」。在飞书里**单聊机器人**，发送页面显示的 `/pair …`。配对码有效期为 5 分钟。收到配对成功后，发送一条普通文本验证收发。

已配对的文本会进入当前主对话，Rally 会把该轮文字答复回到原消息。桌面自己发起的回复、任务后续通知和审批卡留在桌面。主对话正忙于桌面请求时，机器人会提示稍后再发。群聊和附件不进入主对话；Rally 退出后不会继续收发。更换配对账号时，请先在 Rally 断开连接再重新配对。

## 启用 Worker 工具

在飞书卡片打开「允许 Worker 使用飞书工具」。在飞书开放平台为应用开通相应 API 的只读权限，并把要访问的资源共享给该应用。工具以应用身份访问，共享给个人账号的资源不一定对应用可见。

| 能力 | 官方 API |
| --- | --- |
| 读取云文档纯文本 | `docx.v1.document.rawContent` |
| 获取知识库节点信息 | `wiki.v2.space.getNode` |
| 搜索指定多维表格的记录 | `bitable.v1.appTableRecord.search` |

在主对话给出资源链接，让 Rally 派发一个只读任务。主 Agent 只知道这些能力，批准后由 Worker 调用。关闭工具授权会关闭正在使用的工具连接；重新开启后，新建或重新启动的 Worker 会加载工具。

实现使用[飞书官方 Node SDK](https://github.com/larksuite/node-sdk)的 `LarkChannel` 处理长连接、重连和消息队列；工具复用[飞书官方 OpenAPI MCP](https://github.com/larksuite/lark-openapi-mcp)的工具定义和调用处理器，接入 Rally 已有的 MCP 风险和审批链路。单聊配对和长连接方案参考 [OpenClaw 的飞书接入](https://docs.openclaw.ai/channels/feishu)。
