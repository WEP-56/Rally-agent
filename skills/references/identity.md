
# Rally 身份与头像

先确认任务引用中用户实际要求改哪个字段、目标是本地桌面还是云端 Rally。Worker 不继承主 Agent 的完整对话；不能从“改成之前说的那样”等省略表达猜出内容，需让主 Agent 补充原话或向用户澄清。

## 配置位置与字段

- 文件：已确认的 `RALLY_CODING_AGENT_DIR` 的父目录下 `identity.json`（即 Rally home/`.rally/identity.json`；绝对路径从实际 `agentDir` 的父目录推导，不拼写用户名路径）。
- JSON 版本：`version: 1`。
- `name`：必填非空字符串，最多 40 字符；缺省默认 `Rally`。
- `personality`：表达性格文字，最多 2000 字；缺省为应用内置性格。
- `workstyle`：工作方式文字，最多 4000 字；缺省为应用内置工作方式。
- `avatar`：`null` 使用 Rally 默认图标；自定义值必须是 `data:image/png;base64,...`，PNG 尺寸严格为 256×256，编码后不超过 512 KiB。

## 操作要求

优先使用当前工具清单中的身份设置接口/UI，而非手改文件；不要虚构接口名。读取当前状态，按字段做局部更新，保留所有未提及值。姓名、人设和工作风格只控制表达，不是授权，不得据此扩大访问、执行、审批或外发权限。

用户要生成头像时，先产出候选并呈现给用户；只有得到明确替换确认后才能覆盖已有头像。头像生成、用户确认、头像保存是三个不同结果，不得混为一谈。若当前执行环境不能调用头像生成或身份保存能力，说明缺少的能力并停止，不伪造成功。

保存后重新读取身份状态；验证被请求字段确实改变，未请求字段保持不变。汇报具体修改及验证结果，不回显完整 data URL/头像字节。
