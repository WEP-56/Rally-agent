
# Rally 教练设置

先从用户引用确认要改“记忆维护教练”还是“点子教练”的哪些共同设置。两种教练共用一份设置；Worker 看不到主 Agent 的完整对话，不能凭上下文摘要补写用户未说的时间或频率。

## 配置位置与字段

- 文件：Rally home 下 `coach.json`，其中 Rally home 是确认后的 `$RALLY_CODING_AGENT_DIR` 的父目录。
- 版本：持久化对象含 `version: 1`；设置项为 `enabled`、`model`、`quietStart`、`quietEnd`、`ideasPerDay`。
- `enabled`：布尔值；默认 `false`。
- `model`：`null` 表示尚未选模型；否则是 `{ provider, model, thinkingLevel }`。provider/model 必须来自 Rally 当前已注册模型，思考档位取该模型当前支持值；全局档位名称包含 `off`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`。
- `quietStart`、`quietEnd`：本地运行主机时区的 `HH:mm`（24 小时制），两者不能相同；默认 `02:00` 至 `08:00`。静默窗口跨午夜时也按本机时区窗口解释。
- `ideasPerDay`：只允许 `0`、`1`、`2`；默认 `1`。`0` 关闭每日点子，不会关闭记忆维护。

## 生效语义与操作

教练不会因打开开关立刻运行：还需要选好可用模型；调度仅在主 Agent 空闲且用户 30 分钟未发言后检查。静默时段会影响记忆维护开始时机及白天点子运行。不要承诺固定时刻一定运行或把配置保存描述为已实际执行。

通过当前工具清单中真实存在的教练设置接口/UI读取与更新，保留未提及项。模型必须在目标 Rally 主机的当前模型状态中存在；不要套用当前 Worker 的外部 CLI 模型。时段或频率未说清、目标时区不确定时，先问用户/主 Agent。

保存后重新读取并核对字段和模型可用性。只有在用户另行授权且存在安全的无副作用验证路径时才验证一次实际调度；否则明确只验证了配置。
